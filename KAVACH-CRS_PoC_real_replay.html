Autonomous Cyber Reasoning System

This page replays the exact console trace and JSON report produced by an actual run of the KAVACH-CRS Python engine (run_kavach.py --target ./sample_app) against three real, separate vulnerable files. Detection used real AST parsing; reasoning ran in offline-fallback mode (no live network call in this environment); every patch shown was applied to and verified against the real files.

What this page is: a faithful replay of one real execution — not a live simulation with fake logic, and not a fabricated demo. The console log and report JSON below are copied verbatim from an actual terminal run of the Python codebase (included separately as a working CLI tool). What it is not: a live, in-browser Python interpreter — browsers can't run Bandit/pytest directly, so this replays a captured real run for portal/sharing purposes. The runnable source (run_kavach.py + kavach/ modules) is submitted alongside this file for live demonstration. The reasoning stage uses a mechanical, AST-based patch generator (not per-file templates) - verified to generalize correctly on a brand-new, previously-unseen file during testing (see README). Update: a crash in the real-bandit integration path was found and fixed — bandit's JSON output has no field for the enclosing function name (its test_name is the name of the check, not the target function), and the earlier build mistakenly used that as the function name, causing an AttributeError the first time real bandit was installed. DETECT now resolves the real enclosing function from the AST, skips (with a printed note, not a crash) any bandit finding outside a function, and every downstream stage now degrades a finding to "ESCALATED" on unexpected input instead of crashing the whole run. See CHANGELOG.md.
